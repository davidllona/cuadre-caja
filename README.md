# Cuadre de caja

Web de una sola página para cerrar la caja de un comercio desde el móvil.

- Recuento de billetes y monedas tocando cada uno.
- Ventas del día, tarjeta según la caja y total del datáfono.
- Entradas y salidas de dinero del cajón.
- Dice si la caja cuadra, falta o sobra, y da pistas de dónde está el fallo.
- Calendario de cierres con el detalle de cada día.

Es un único `index.html`, sin dependencias ni servidor. Los datos se guardan en el navegador del dispositivo (`localStorage`).
